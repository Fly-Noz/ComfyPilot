# 04 · 鸿蒙视频/音频产物播放

Status: needs-triage
Type: task

## 问题

安卓产物预览对内嵌视频使用 `VideoView`；鸿蒙当前对视频、音频只提供下载，提示用户用系统应用打开。

## 范围

- 先决定产品策略：内置播放，还是保持“只下载”；
- 若内置播放：使用鸿蒙系统播放器能力，处理 HTTP `/view` 地址、缓冲、切后台、错误和生命周期；
- 音频至少提供播放/暂停和时长；
- 与图片预览共用产物页面的返回/下载布局。

## 验收

- 若采用内置播放：真机能播放一个 ComfyUI 产出的常见视频格式；
- 404/编码不支持/网络中断时显示明确错误，不无限转圈；
- 切后台暂停，返回后不自动抢播；
- 下载路径保持不变。
