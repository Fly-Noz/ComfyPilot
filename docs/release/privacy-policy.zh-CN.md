# ComfyPilot 隐私政策（模板）

生效日期：____年__月__日

ComfyPilot（以下简称“本应用”）是一个 ComfyUI 客户端。本应用**不运营服务器**，
只连接你自行填写的 ComfyUI 地址。请在上架前把本文件发布到公网 URL，并在应用内提供入口。

## 一、我们收集的信息

本应用**不收集、不上传**任何个人信息到开发者服务器。

仅在你本机保存以下数据，用于应用功能：

| 数据 | 用途 | 存放位置 |
|---|---|---|
| ComfyUI 服务器地址 | 下次打开直接连接 | 本机应用存储 |
| 客户端 ID | 与服务器保持同一 WebSocket 会话 | 本机应用存储 |
| 工作流参数草稿 | 再次打开工作流时恢复你改过的参数 | 本机应用存储 |
| 任务记录与产物引用 | 任务列表、断线恢复 | 本机应用存储 |
| 诊断日志 | 排查连接/任务问题，仅本机保留最近若干条 | 本机应用存储 |

卸载应用即删除上述全部数据；也可在「设置 → 工作流参数 → 恢复所有参数设置为默认」
清除参数草稿。

## 二、权限说明

| 权限 | 用途 |
|---|---|
| 网络访问 | 连接你填写的 ComfyUI 服务器 |
| 网络状态 | 判断当前网络是否可用 |
| 通知 | 后台任务进度与完成提醒（可拒绝，不影响使用） |
| 后台运行 | 任务运行期间保持连接（可随时关闭） |
| 读取图片/文件 | 你主动选择图片上传到自己的 ComfyUI 服务器 |

## 三、第三方

本应用不集成广告、统计、推送 SDK，不向第三方共享数据。
你连接的 ComfyUI 服务器由你自行提供，其数据处理行为由该服务器的运营者负责。

## 四、未成年人

本应用不面向未成年人单独提供服务，也不收集年龄信息。
