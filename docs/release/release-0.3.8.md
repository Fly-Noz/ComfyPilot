# ComfyPilot 0.3.8

发布日期：2026-11-22

## 下载

- **Android**：`ComfyPilot-0.3.8.apk`，Android 8.0+，项目密钥签名，直接安装。
- **HarmonyOS NEXT**：`entry-default-unsigned.hap`，5.0.0(12)+，未签名，需使用发布证书签名后安装。
- **iOS**：`ComfyPilot-unsigned.ipa`，iOS 17.0+，未签名测试包，需自行签名后安装。

## 本次更新

### 图片蒙版编辑

- Android、HarmonyOS、iOS 同步支持图片节点蒙版编辑；
- 支持画笔、橡皮擦、撤销、清空、笔刷大小和双指缩放；
- 蒙版保存后生成带透明区域的 PNG 并回写图片字段；
- 再次编辑可恢复上次蒙版，换图后自动清空旧蒙版；
- 仅允许编辑本次从相册上传的原图；直接引用主机文件名时会提示先上传，避免拿错底图。

### 工作流与主机状态

- 工作流增加会话内缓存和后台更新检查，再次打开更快；
- 主机状态支持实时 CPU/GPU 指标，收起状态优先显示动态数据；
- 修复安卓节点关闭状态重启后恢复方向错误；
- 支持前端虚拟节点、SetNode/GetNode 总线、节点隐藏和采样预览手动刷新。

### 问题修复

- 修复安卓蒙版 PNG 丢失 alpha，生成图不按蒙版执行的问题；
- 安卓蒙版改用完整原图，上传结果直接在图片卡片内提示；
- 修复鸿蒙蒙版坐标单位、PixelMap 通道顺序、历史蒙版恢复、画笔性能和工具图标状态问题；
- 修复安卓主机状态摘要拥挤、缓存重复请求节点定义等问题。

## 已知限制

- **iOS 尚未进行真机验证**：目前只完成模拟器构建和 UI 流程验证，没有在真实 iPhone 上完整跑通。
- **iOS 蒙版功能尤其需要重点验证**：涉及图片解码、Canvas/PixelMap、透明通道、手势和上传编码，模拟器与真机可能存在差异。若出现蒙版偏移、颜色异常、无法保存或生成图不按蒙版执行，欢迎反馈并附上设备型号、iOS 版本和复现步骤。
- iOS 为未签名 IPA，安装前需要自行签名；后台保活受 iOS 系统限制。
- HAP 同样未签名，需要自行使用发布证书签名。
- 自签名 IPA 的更新只能跳转下载页，不能自动安装。
