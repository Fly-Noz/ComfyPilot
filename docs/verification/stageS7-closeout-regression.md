## 回归过程

1. 从相册选择图片，字段从旧的 `测试图 (17).png` 更新为服务器返回的
   `1000198533.png`，随后再次上传得到 `1000198534.png`。
2. 再次打开相册后直接返回，字段保持原值，没有“上传中”残留。
3. 打开 `宽高比` 下拉，选择 `1:1 (Square)`，字段显示同步更新。
4. 关闭两个节点图：
   - 输入区显示 `节点图未启用，不会被提交`；
   - 底部显示 `不可提交：没有启用任何节点图，不能提交`；
   - 显示 `0 个会提交`，提交按钮不可用。
5. 重新启用节点图后点提交：
   - 先弹出“提交前确认”，列出
     `已忽略 1 个未连接到输出节点的节点`；
   - 点“取消”回到详情页，没有创建任务；
   - 再次提交并点“仍然提交”，任务进入队列、执行并完成。
6. 产物页确认 `SaveImage` 文件名带本次 token `4159e3fc4a`。
7. 下载新产物，`/sdcard/Download/` 中存在：
   `QW21-%date_yyyyMMddhhmmss%_4159e3fc4a_00001_.png`；
   之前同名下载保留为 `..._00001_ (1).png`，避让生效。
