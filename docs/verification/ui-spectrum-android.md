## 设计要点

- **背景**：`SpectrumBackdrop` 画三层径向色晕（紫 / 青 / 粉），深浅两套颜色不同。
- **卡面**：半透明填充 + 1px 边框；Compose 没有可用的背景模糊，玻璃感靠透明度和色晕透出近似，未使用 `RenderEffect`。
- **强调**：青绿→紫→粉渐变用于主按钮、选中芯片、进度条与百分比数字（`TextStyle(brush=)`）。
- **排版**：标题 700 权重、负字距；数值与标签走等宽字体。
- **系统栏**：深色模式浅色图标、浅色模式深色图标；状态栏/导航栏透明，内容延伸到边。

## 行为保持

- 连接 → 自动进入目录；目录自动拉取、置顶排序、置顶后滚动到顶部。
- 详情：图开关 → 可达节点重算、切换后列表回到顶部、置顶保存、展开状态、120ms 防抖决策、提交前警告弹窗、阻断原因、上传图片、全部节点面板、失败横幅关闭。
- 任务：取消、产物预览、下载（含旧系统存储权限）。
- 诊断页保留连接层入口；返回逻辑与原实现一致（新增设置页仅多一个返回目标）。

## 全部节点搜索与筛选（2026-10-23）

- 搜索：名称、类型、`#id`、备注、输入类型（`STRING` / `IMAGE` 等），无关键词即全量。
- 筛选：图像输入、文本输入、数值输入、待填写；前三者之间是「任一命中」，待填写与其他项叠加时是「同时满足」。
- 分类在 shared 层 `WorkflowNodeTraits`（有单测），只读节点定义里已有的输入类型，不额外请求主机。
- 实测：`image` 搜索 28/73；图像输入筛选 23/73。

## 节点备注

- 备注按「工作流路径 + 节点 id」存本机 `SharedPreferences`（`NodeNoteStore`，有单测）。
- 备注后卡片标题显示备注名，副标题保留原始 `类型 · 节点名`；「全部节点」同步显示。
- 入口是卡片上的笔形图标；带备注时图标高亮，弹窗里可「清除备注」。
- 实测：给 #475 备注 `cover` 后标题变为 `#475 cover`，重启应用后仍在。

## 上传图片预览

- 仅显示本次会话上传的图：上传成功后解码一张 ≤512px 缩略图，跟 `nodeId:inputName` 绑定，显示在「更换图片」左侧 56dp 圆角块里。
- 不额外请求 `/view`，所以工作流原本引用的文件名不会显示缩略图（按需求只做本次上传）。
- 实测：#475 上传 942KB 图后出现缩略图，按钮文案变「更换图片」。

## 卡片图标

- 置顶、备注、展开改为手绘 Canvas 图标（顶栏箭头 / 铅笔 / 折线箭头），不再引入图标包；置顶与备注激活时用强调色底。
## 节点图顺序（2026-10-23）

- 启用中的节点图整组排在前面，未启用的整组后移；组内顺序仍按主机返回的图组顺序，不重排。
- 子图跟着父图走；不属于任何图组的节点仍在末尾。
- 实测：只启用「生图」时，「生图 · 11 个节点 · 11 个会提交」升到首位，「图像编辑」落在后面并标「未启用」；两张都启用时恢复主机顺序。
## 操作动画（2026-10-23）

- 详情页「输入 / 预览」切换：淡入 + 轻微横向位移（170–200ms），不再硬切。
- 节点卡片展开/收起：`AnimatedVisibility` 竖向扩展 + 淡入（220ms / 180ms）。
- 节点图下拉面板：出现时淡入 + 从按钮下沿轻微放大（150ms）。
- 筛选 chip、卡片图标：选中态颜色过渡（160–170ms），不再瞬间跳色。
- 节点列表：`animateItem()`，启用/停用节点图导致整组重排时平滑移动。
- 全部用 Compose 自带 API，不引第三方动画库；系统关闭动画时会自行缩短。

## 连接自愈（2026-10-23）

- 排队看门狗：`Queued` 超过 10s 没有任何事件时，主动 `/history` 复核（不关 socket、不递增 generation）；仍在线就顺延静默预算。
- 回前台对账：`LifecycleResumeEffect` → `SessionRuntime.reconcile()`，对每个非终态任务发一次 `/history`。
- 心跳说明：OkHttp 不暴露 WebSocket ping 帧，没有做协议级心跳；改以“有任务时长时间无事件”作为断线信号。
- 单测：`QueuedWatchdogTest`（4 条：静默触发、窗口内不触发、回前台不复位、空列表无副作用）。

## 长文本输入换行（2026-10-23）

- `STRING` 类型字段改用多行输入：`singleLine = false`、`minLines = 3`、最多 12 行，超出后输入框内部滚动；提示词不再挤成一行。
- 其余类型保持单行（数字、下拉、布尔不受影响）；多行字段用非等宽字体，中文和长句更好读。
- 鸿蒙同一个分支改用 `TextArea`（高度 96vp，自动换行、内部滚动）。
